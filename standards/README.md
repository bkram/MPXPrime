# Standards and reference documents

The specifications this project implements. The PDFs themselves are **not**
redistributed here (they are excluded in `.gitignore`); download them from the
issuing bodies and drop them in this folder if you need them locally.

Not to be confused with `docs/`, which holds this project's own manuals.

| File | Standard |
|---|---|
| `EN50067_RDS_Standard.pdf` | EN 50067 -- RDS specification |
| `IEC-62106-2-2018.pdf` | IEC 62106-2 -- RDS, message format |
| `IEC-62106-6-2023.pdf` | IEC 62106-6 -- RDS, Open Data Applications |
| `R-REC-BS.450-4-201910-I!!PDF-E.pdf` | ITU-R BS.450 -- FM sound broadcasting transmission standards |
| `rds-docs-unlocked.pdf` | UECP SPB 490 -- Universal Encoder Communication Protocol |
| `trev_307-radiotext.pdf` | EBU Technical Review -- RadioText and RT+ |

Related standards used but not stored here: ITU-R SM.1268 (deviation
measurement), ITU-R BS.412 (MPX power), NRSC-4-B (RBDS), 47 CFR 73.322.
